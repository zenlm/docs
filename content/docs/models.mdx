# Models

Zen LM is the open model family of Zoo Labs Foundation, a 501(c)(3) non-profit, chosen for agentic coding that runs on your own machine and for marketing work.

## Zen 6 — Available Now

| Model | Weights | Reads | Context | API id |
|-------|---------|-------|---------|--------|
| **Zen 6** | 27B dense, NVFP4 | text, images, video | 262,144 native; 1,048,576 with YaRN | `zen6` |
| **Zen 6 Flash** | 27B ternary, 1.77 bits per weight (5.95 GB) | text, images | 262,144 native | `zen6-flash` |

- [Zen 6](/docs/models/zen6) — specifications, measurements and serving commands
- [HuggingFace: zenlm/zen6](https://huggingface.co/zenlm/zen6) | [HuggingFace: zenlm/zen6-flash](https://huggingface.co/zenlm/zen6-flash)

## Zen 7 — Research Preview

The next open-weight generation after Zen 6. It has no weights yet and cannot be called. [Request access](https://hanzo.ai/research-access).

#### Zen4 Mini (4B)

Ultra-efficient for edge and mobile. Full quality at 4B parameters.

- [HuggingFace](https://huggingface.co/zenlm/zen4-mini) | [GitHub](https://github.com/zenlm/zen4-mini)

#### Zen4 (8B)

The standard model. Excellent balance of quality and efficiency.

- [HuggingFace](https://huggingface.co/zenlm/zen4) | [GitHub](https://github.com/zenlm/zen4)

Professional-grade for demanding tasks. Strong reasoning and code generation.

#### Zen4 Max (30B MoE)

Efficient mixture-of-experts model. 30B total with only 3B active via MoE.

- [HuggingFace](https://huggingface.co/zenlm/zen4-max) | [GitHub](https://github.com/zenlm/zen4-max)

#### Zen4 Pro Max (80B MoE)

The largest Zen4 consumer model. Hybrid Gated DeltaNet + Gated Attention + MoE architecture.

- [HuggingFace](https://huggingface.co/zenlm/zen4-pro-max) | [GitHub](https://github.com/zenlm/zen4-pro-max)

| Format | Use Case | Platform |

| **SafeTensors** | Full precision, transformers | All |
| **GGUF** | Quantized, llama.cpp/Ollama | All |
| **MLX** | Apple Silicon optimized | macOS |

## Usage

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "zen6", "messages": [{"role": "user", "content": "Hello!"}]}'
```

Every hosted Zen id, with its context window and price, is one request away: `curl -s https://api.hanzo.ai/v1/models`.

## Multimodal & Specialized

| Model | Type | Description |
