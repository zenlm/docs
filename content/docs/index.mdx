# Zen LM

Zen LM is the open model family of Zoo Labs Foundation, a 501(c)(3) non-profit. It is chosen for two jobs:

- **Agentic coding that runs on your own machine** — long context, tool use and fast decoding.
- **Marketing work** — content, campaigns and brand voice, with the images and video behind them.

## Available now: Zen 6 and Zen 6 Flash

| Model | Weights | Reads | Context | API id |
|-------|---------|-------|---------|--------|
| **Zen 6** | 27B dense, NVFP4 | text, images, video | 262,144 native; 1,048,576 with YaRN | `zen6` |
| **Zen 6 Flash** | 27B ternary, 1.77 bits per weight (5.95 GB) | text, images | 262,144 native | `zen6-flash` |

Zen 6 ships a speculative drafter that took code completion from 62.4 to 141.2 tokens per second on one DGX Spark. Zen 6 Flash runs on an Apple Silicon laptop in 7.84 GB with its vision projector and a 32K cache. See [Zen 6](/docs/models/zen6).

## Research preview: Zen 7

Zen 7 is the next open-weight generation. It has no weights yet and cannot be called. [Request access](https://hanzo.ai/research-access).

## Quick Start

### Call Zen 6

```bash
curl https://api.hanzo.ai/v1/chat/completions \
  -H "Authorization: Bearer $HANZO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "zen6", "messages": [{"role": "user", "content": "Hello"}]}'
```

### Run it yourself

```bash
hf download zenlm/zen6 --local-dir zen6
```

The [Zen 6 page](/docs/models/zen6) has the serving commands for both builds.
